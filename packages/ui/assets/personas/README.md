# Agent person avatars

Open Peeps by Pablo Stanley, generated with DiceBear (`open-peeps`, 9.x). License: CC0 1.0.

Clothing is limited to the product's terracotta and grays. Masks, glasses, facial hair, and
styles that hide the face or merge with a dark background are left out.

`agentPersonaAvatarCount` in `server/internal/handler/agent_avatar.go` must match the number of
files here.
