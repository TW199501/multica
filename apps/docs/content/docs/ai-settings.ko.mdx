## 워크스페이스 AI 설정

Web 또는 Desktop에서 워크스페이스 `owner`나 `admin`이 에이전트 목록의 AI 설정을 엽니다. 이 설정은 메시지 다듬기에 사용되며 에이전트 자체의 런타임이나 모델 설정을 바꾸지 않습니다.

1. 공급자 탭에서 공급자, OpenAI 호환 API 엔드포인트, 모델 ID, API 키를 입력합니다. 자체 호스팅(llama.cpp)과 사용자 지정 엔드포인트는 키 없이도 사용할 수 있습니다. 목록에 없는 모델 ID도 직접 입력할 수 있으며, 키 없는 서버가 모델을 제공하면 모델을 비워 둘 수도 있습니다.
2. 연결을 테스트합니다. 현재 입력값과 고정된 짧은 프롬프트만 사용하며 사용자 콘텐츠는 보내지 않습니다. 테스트는 변경 사항을 저장하지 않습니다.
3. 모델 용도 탭에서 대화 AI 프롬프트와 필요한 경우 생각 기능 끄기를 설정합니다. skill을 선택하면 해당 내용이 프롬프트를 대신합니다. 직접 편집하려면 skill 선택을 해제합니다.
4. 공통 저장 버튼을 누릅니다. 탭을 전환해도 저장하지 않은 입력은 유지됩니다. 페이지를 떠나기 전에 저장 버튼 옆의 오류를 확인하세요.

공급자와 호스트가 같으면 키 입력란을 비워도 저장된 키가 유지됩니다. 공급자나 호스트를 바꾸면 키가 필요한 공급자는 다시 입력해야 합니다. 저장된 키는 마스킹되어 표시됩니다.

모델 추천, 유형, 시각 기능, 컨텍스트 및 출력 한도는 내장 카탈로그의 참고 정보이며 계정의 실시간 접근 권한 확인 결과가 아닙니다. 다듬기에는 채팅 모델이 필요합니다. 모델 입력란 옆의 매개변수 버튼을 누르면 모델의 유형, 비전 지원, 한도를 볼 수 있습니다. 키를 입력하면 공급자에게서 모델 목록을 직접 가져옵니다. 프롬프트를 보내지 않으므로 토큰을 쓰지 않습니다. 공급자가 응답하지 않으면 내장 추천을 표시하며 직접 입력할 수도 있습니다.

현재 워크스페이스당 구성 하나와 선택 모델 하나를 지원합니다. 구성 생성·복제·삭제, 사용자 지정 헤더, 모델 추가, 임베딩·재순위화·결정 모델 할당은 비활성화되어 있으며 향후 기능으로 표시됩니다.

카탈로그에 없는 모델은 이름으로 유형을 추정하며, 알 수 없는 이름은 채팅으로 표시합니다. 이 표시는 호환성을 보장하지 않습니다.

## 초안 다듬기

워크스페이스 AI를 사용할 수 있으면 채팅, 태스크 댓글, 답글, 댓글 편집, 태스크 생성 및 빠른 생성에서 다듬기 버튼이 표시됩니다. 텍스트를 입력하고 첨부 파일 업로드가 끝날 때까지 기다리세요.

원문과 편집 가능한 결과를 비교하고 수정하거나 다시 생성합니다. 메시지를 보내는 입력란의 보내기는 첨부 파일과 수신 대상을 포함한 원래 전송 흐름을 사용합니다. 댓글 편집과 태스크 생성의 적용은 결과를 편집기에 넣기만 하므로 이후 저장 또는 생성이 필요합니다. 확인하지 않고 돌아가려면 제목 표시줄의 닫기 버튼을 사용합니다.

실패하면 원문을 유지하고, 재생성 실패 시 이전 결과를 유지합니다. 전송 실패 시 대화 상자가 열린 채로 남아 다시 시도할 수 있습니다. 멘션·링크·코드 보호 대상이 누락된 결과는 거부됩니다. 확인 전에 내용을 검토하세요.

### 보내기 전에 다듬기

설정의 환경설정 → 댓글 및 채팅에서 전송 전 다듬기를 켜면 채팅, 댓글, 답글 전송 전에 확인 창이 열립니다. 이 기기 설정은 기본적으로 꺼져 있습니다. AI를 사용할 수 없거나 첨부 파일만 있는 초안은 일반 전송을 사용합니다. 설정을 끄면 수동으로 다듬기를 선택할 수 있습니다.

초안과 관련 대화 맥락은 설정한 엔드포인트로 전송됩니다. 초안의 멘션·링크·코드는 자리표시자로 바뀌지만 맥락은 **마스킹되지 않습니다**. 자신의 채팅 기록 또는 태스크 제목·설명과 최근 댓글／스레드 답글이 포함될 수 있습니다. 제한은 [환경 변수](/environment-variables)를 참고하세요.

## 선택적 결정 지시

채팅, 댓글, 답글에서는 실행 승인 또는 추가 논의를 선택할 수 있습니다. 선택만으로 전송되지 않습니다. 승인할 때만 단일／다중 에이전트 실행 방식이 나타나며 메시지를 보낼 때 지시가 추가됩니다.

단일 에이전트는 `superpowers:executing-plans`, 다중 에이전트는 `superpowers:subagent-driven-development`를 지정합니다. 추가 논의는 시작하지 말고 기다리라고 지시합니다. 이는 메시지의 지시이며 별도의 실행 또는 권한 체계가 아닙니다. 빈 선택지로 돌아가면 일반 메시지가 됩니다.

## 자체 호스팅 조건

설정 저장과 다듬기를 사용하려면 운영자가 안정적인 `MULTICA_AI_SECRET_KEY`를 설정해야 합니다. 키를 잃거나 바꾸면 저장된 AI 키를 복호화할 수 없습니다. `MULTICA_LLM_*`로 대체되지 않습니다.

엔드포인트는 Multica 백엔드에서 접근할 수 있어야 합니다. localhost와 사설 주소는 기본적으로 차단되며 `MULTICA_AI_ALLOW_CIDRS`로 명시적으로 허용해야 합니다. 허용 범위는 모든 워크스페이스 소유자에게 적용되므로 좁게 지정하세요. [환경 변수](/environment-variables)를 참고하세요. 선택 사항인 `deploy/llama/`는 직접 제공한 GGUF 파일로 별도 모델 서버를 실행하며 모델을 다운로드하지 않습니다.
