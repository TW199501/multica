## 配置工作区 AI

在 Web 或 Desktop，由工作区 `owner` 或 `admin` 打开**智能体 → AI 设置**。这组配置用于对话优化，不会替换智能体自身的运行时或模型配置。

1. 在模型供应商中选择供应商，填写兼容 OpenAI 格式的 API 端点、模型 ID 和 API 密钥。自建（llama.cpp）与自定义端点可以不使用密钥。模型可手动输入，不限于建议列表；无密钥端点若由服务端提供模型，也可留空。
2. 测试连接。测试使用表单当前的值和固定短提示，不含用户内容；测试不会保存修改。
3. 在模型配置中设置对话 AI 的提示词与可选的关闭思考。选择 skill 后会使用其内容替代可编辑提示词；取消 skill 选择即可自行编辑。
4. 点击共用的保存按钮。切换标签页会保留未保存的修改；离开前检查保存按钮旁的错误。

供应商与主机不变时，密钥栏留空会保留已存密钥。更换供应商或主机后，需要密钥的供应商必须重新输入。已存密钥只显示遮蔽值。

模型建议、类型、视觉能力与上下文／输出上限来自随版本附带的目录，不代表实时验证了账号权限。优化需要对话模型；非对话类型会显示提醒。点击模型栏旁的参数按钮，可以查看模型的类型、视觉能力和上限。填入密钥后，模型列表会直接向供应商查询，不发送提示词，也不消耗 token。供应商无法响应时，改用内置建议，仍可手动输入。

目前每个工作区只有一组配置和一个选用模型。创建、复制、删除配置、自定义请求头、添加模型，以及嵌入、重排序、决策模型配置仍停用，等待后续开放。

目录找不到模型时，类型会根据名称推测；无法识别的名称默认显示为对话类型。标签仅供参考，不代表兼容性验证。

## 优化草稿

工作区 AI 可用后，聊天、任务评论、回复、编辑评论，以及创建／快速创建任务的编辑器会提供对话优化。先输入文字，并等待附件上传完成。

对话框并列显示原文与可编辑结果。可检查、修改或重新优化。聊天、评论和回复中的发送会走原输入框流程，连同附件和收件对象发送；编辑评论与创建任务中的采用只把结果放回编辑器，之后仍需保存或创建。不确认时，使用标题栏关闭按钮返回。

失败会保留原文；重新优化失败则保留之前的结果。发送失败时对话框保持打开以便重试。提及、链接与代码受到保护，丢失受保护内容的结果会被拒绝；确认前仍应检查文字。

### 发送前优化

在**设置 → 偏好设置 → 评论与聊天**启用对话优化，发送聊天、评论和回复前先打开确认框。这是当前设备的偏好，默认关闭。工作区 AI 不可用或草稿只有附件时，仍使用正常发送流程。关闭偏好即可手动选择何时优化。

### 哪些内容会传给模型？

草稿和相关上下文会发送到工作区配置的端点。草稿中的提及、链接与代码被替换为占位符，但上下文**不做遮蔽**。上下文可能包含自己的聊天历史，或任务标题、描述与近期评论／讨论串回复。限制与端点控制见[环境变量](/environment-variables)。

## 可选的决议指令

聊天、评论和回复可选择批准执行或继续讨论，选择本身不会发送。批准时才显示单智能体／多智能体执行方式；指令在实际发送消息时附加。

单智能体批准指定 `superpowers:executing-plans`，多智能体批准指定 `superpowers:subagent-driven-development`；继续讨论要求智能体暂不开始。这些是消息指令，不是独立的执行或权限机制。选择空选项即可发送普通消息。

## 自托管前提

部署管理员需设置稳定的 `MULTICA_AI_SECRET_KEY`，才能保存配置并使用优化。丢失或更换后，已存 AI 密钥无法解密。这些功能不会回退到 `MULTICA_LLM_*`。

端点必须能从 Multica 后端访问。私有地址与 localhost 默认被拒绝，需由 `MULTICA_AI_ALLOW_CIDRS` 明确允许；范围适用所有工作区所有者，应尽量缩小。见[环境变量](/environment-variables)。可选的 `deploy/llama/` 使用你提供的 GGUF 文件运行独立模型服务，不会自动下载模型。
